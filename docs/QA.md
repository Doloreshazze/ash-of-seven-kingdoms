# QA-план первого прототипа

В этой среде Godot Runtime отсутствует. Поэтому все следующие тесты **не считаются пройденными** до выполнения на реальном движке.

## 1. Технический smoke test (GitHub Actions)
- Импорт `.png`, `.wav`, `Main.tscn` и `Game.gd` без ошибок.
- Запуск в headless Godot на несколько кадров.
- Экспорт Windows; проверка наличия `.exe` и `.pck` в артефакте.

## 2. Ручной Windows-тест
- Главный экран открывается, Enter начинает пролог.
- A/D ведут героя, Space прыгает, J бьёт, K тратит ману и выпускает огонь.
- Оба вида атак наносят урон волкам/призракам/культистам.
- Враги причиняют урон; при 0 HP показывается смерть и возрождение.
- После трёх контрольных точек их можно использовать для восстановления HP/маны.
- Повторный запуск загружает последнее святилище.
- Морвен атакует, проигрывает при 0 HP, появляется выбор F/G и один из двух финалов.
- F1 переключает русский / английский на всех экранах, включая меню и диалоги.
- Esc/P корректно ставят паузу.

## 3. Ручной Android-тест
- 1280×720 интерфейс масштабируется без обрезания на соотношениях 16:9 / 20:9.
- Два пальца: движение и одновременно меч/магия/прыжок.
- Экран не гаснет во время активного боя, управление не блокируется системной навигацией.
- Игра сохраняется и восстанавливается после уничтожения процесса.
- Отсутствуют запросы персональных разрешений и соединения с серверами.
- Отслеживание частоты кадров и пиков потребления памяти на Galaxy A72.

## 4. Известные риски
- Godot Android Export Templates и Android SDK требуют отдельной подготовки окружения.
- Локальная кириллица зависит от встроенного шрифта Godot — проверить отображение всех символов.
- Весь код сейчас находится в одном игровом скрипте, что временно допустимо для прототипа, но потребуется декомпозиция.
- Иллюстрация леса пока не разбита на слои и повторно используется во всех четырёх областях.
